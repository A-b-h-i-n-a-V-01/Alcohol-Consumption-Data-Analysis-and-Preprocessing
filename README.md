# Alcohol Consumption Data Analysis and Regression

## Overview

This project focuses on data preprocessing, exploratory data analysis (EDA), feature engineering, and machine learning using an alcohol consumption dataset.

The project demonstrates essential data science techniques including handling missing values, outlier detection, label encoding, one-hot encoding, and building a Linear Regression model to predict alcohol consumption levels.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Project Workflow

1. Load dataset
2. Explore dataset structure
3. Analyze data types and descriptive statistics
4. Handle missing values using median imputation
5. Visualize distributions using histograms
6. Detect outliers using the IQR method
7. Perform Label Encoding
8. Perform One-Hot Encoding
9. Prepare data for machine learning
10. Train a Linear Regression model
11. Evaluate model performance using MSE and R² Score

## Data Preprocessing Techniques

### Missing Value Handling

* Median imputation for numerical columns

### Outlier Detection

* Interquartile Range (IQR) Method
* Boxplot visualization

### Encoding

* Label Encoding for Country column
* One-Hot Encoding for Continent column

## Machine Learning Model

### Linear Regression

Target Variable:

* total_litres_of_pure_alcohol

Features:

* beer_servings
* spirit_servings
* wine_servings
* continent-based encoded features

### Model Evaluation

The model is evaluated using:

* Mean Squared Error (MSE)
* R² Score
