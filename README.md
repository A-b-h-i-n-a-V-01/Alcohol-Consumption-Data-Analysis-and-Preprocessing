x# Alcohol Consumption Data Preprocessing

## Overview

This project focuses on data preprocessing and exploratory data analysis (EDA) using an alcohol consumption dataset.

The project demonstrates essential data science techniques including handling missing values, outlier detection, label encoding, and one-hot encoding.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow

1. Load dataset
2. Explore dataset structure
3. Analyze data types and statistics
4. Handle missing values using median imputation
5. Visualize distributions using histograms
6. Detect outliers using IQR method
7. Perform Label Encoding
8. Perform One-Hot Encoding
9. Prepare data for machine learning

## Data Preprocessing Techniques

### Missing Value Handling
- Median imputation for numerical columns

### Outlier Detection
- Interquartile Range (IQR) Method
- Boxplot visualization

### Encoding
- Label Encoding for Country column
- One-Hot Encoding for Continent column
